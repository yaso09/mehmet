# Güvenlik Politikası

## Desteklenen Sürümler

| Sürüm | Destekleniyor |
|-------|---------------|
| 0.3.x | Evet |
| 0.2.x | Evet |
| < 0.2 | Hayır |

## Güvenlik Açığı Bildirimi

Güvenlik açığı bildirmek için lütfen GitHub üzerinden gizli bir issue
açın veya açık bir güvenlik sorunu olduğunu düşünüyorsanız bir PR gönderin.

## Otomasyon Notu

Bu proje otonom bir AI ajanı tarafından geliştirilmektedir. `OPENCODE_API_KEY`
secret'ı dışında herhangi bir kimlik bilgisi depoda saklanmaz. Değişiklikler
yalnızca depo içindeki dosyalarla sınırlıdır.
